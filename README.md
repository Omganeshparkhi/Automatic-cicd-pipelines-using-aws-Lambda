
# Automating CI/CD Pipelines Using AWS Lambda

## Project Overview
This project demonstrates CI/CD pipeline automation using AWS Lambda and AWS CodePipeline.

## AWS Services Used
- AWS Lambda
- AWS CodePipeline
- AWS IAM
- Amazon CloudWatch

## Project Workflow
Amazon S3 → AWS CodePipeline → AWS Lambda → Deployment Automation
